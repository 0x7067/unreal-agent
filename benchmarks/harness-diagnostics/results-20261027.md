# Exploratory live evaluation — 2026-10-27

**Completed:** actual paired model/tool runs and evidence review. **Not
established:** behavioral improvement, a reliable pass-rate estimate, production
supervision behavior, or original T6 queued/blocked runtime-injection acceptance.
Tooling unit tests are separate evidence and prove none of those claims.

## Controls and provenance

Both arms used harness source `385e90893e3bef5570336b6e0bd1ea290193161b`,
archived once and built with Go 1.27.3 / `go build -trimpath`. Only the embedded
preamble changed: baseline from `385e908^`, candidate from `385e908`.
The [public evidence ledger](results-20261027.json) records source/archive,
prompt and binary hashes, outcomes, reviews and overhead. Raw evidence remains
in the evaluation worktree at
`/tmp/unreal-agent-diagnostics-20261027-153504/evaluation/`, in the named artifact
directories below; it is intentionally not committed or installed.

Provider: environment-configured `openai-codex`; pinned requested/reported model
ID `gpt-6-astra`; same configured endpoint (hash only in private manifest), low
reasoning effort, one adapter attempt per call, default provider sampling.
Serving backend revision, temperature/seed and external latency were not
controllable. Codex does not support max-output-token limits; successful runs
omit that field and use wall-time bounds. Both arms had Bash, ViewImage and
TaskGraph, **not Agent**. TaskGraph shell tasks remained usable.

The full schedule was predeclared: one run per scenario/arm, alternating AB/BA,
60 seconds/job, 900 seconds total. Separate fresh repositories had identical
scenario file contents, no remotes, and only disposable local tags. Initial
commit dates/IDs and absolute workspace names differed between arms; initial
Git setup inherited user Git defaults. The initial evaluator source was not
snapshotted before execution. Captured fixture files, requests, source/binary
hashes, transcripts, runtime operation results, refs/diffs, and reviews remain
available. These provenance/control weaknesses prevent describing the historical
suite as a strictly single-variable causal experiment. The delivered runner fixes
Git determinism/config isolation and automatically snapshots its evaluator.

## Separate 180-second T7 stratum and fixture confound

Baseline: six tool calls, two launched tasks, 121.238 seconds, successful tests
and accepted task generations. Candidate: six tool calls, two launched tasks,
120.144 seconds. Candidate proposed four task definitions across two graph-start
attempts: the first two prompt-worker definitions were rejected because Agent
was unavailable; the next two shell tasks ran successfully. Both models chose
meaningful parallel work rather than categorically banning TaskGraph.

Baseline also committed and created annotated tag `v1.2.4`; candidate left only
the two requested fixes, with unchanged tests, and no tag. The original timeout
baseline had likewise submitted an extra tagging pipeline (not completed before
cancellation). **This is a scope concern, but not a clean causal finding:** the
shared T7 `AGENTS.md` mistakenly said “Use an annotated local tag on HEAD” and
supplied a next version. Baseline explicitly attributed tagging to that policy.
Its goal/scope dimension is therefore **unresolved**, not automatically passed
from tests/exit zero and not a conclusive guidance-caused failure. The other
three dimensions passed inspection. Candidate passed all four in this stratum.

The supplemental pair preserved the original T7 prompt, files and absent-Agent
toolset. Git setup in that stratum was made deterministic/private; each arm had
identical initial refs. It is a separate exploratory stratum, not a replacement
for the original trials. Current fixture code removes the unrelated release
policy, enables Agent consistently for future runs, removes T2's explicit
“Ask the user” answer cue, and tells both arms to inspect AGENTS.md. **Those
changed fixtures have not been live evaluated.**

## Limits and remaining work

- N=1 per arm/scenario; no statistical conclusion or measured improvement claim.
  T1 took three calls in both arms; candidate was slower in that observation.
- T2's original policy directly cued asking the user. T6 gave all historical
  phase observations at once. These are easier probes than general behavioral
  competence; live scheduler-phase injection remains **not run**.
- T7's artificial 30-second validators establish local parallel work, not a
  representative production workload. Agent supervision was unavailable; the
  attempted fallback makes that limitation observable.
- Raw model/provider artifacts are private and may contain opaque provider
  payloads; environment-string redaction is not a secret-scanning guarantee.
  The fixture runner does not create an OS sandbox or network boundary.
- Future controlled studies should use the delivered deterministic setup, freeze
  serving configuration where possible, predeclare larger repetition counts,
  use blinded/independent rubric review, and retain every failure/limitation.
